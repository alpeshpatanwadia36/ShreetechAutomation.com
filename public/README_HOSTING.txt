HOW TO DEPLOY ON CPANEL / HOSTINGER / GODADDY / WORDPRESS HOSTING:

OPTION 1: Standard Root Domain (e.g., https://yourdomain.com/)
1. Log in to your Web Hosting cPanel or File Manager.
2. Navigate to your root directory: public_html/
3. Upload this ZIP file (or extracted files).
4. Extract all files directly into public_html/ so that `index.html` sits directly inside public_html/.
5. Done! Your high-performance portal is live with all 19+ industrial products, 
   instant quotation calculator, and WhatsApp direct links.

OPTION 2: Sub-folder / Sub-directory (e.g., https://yourdomain.com/portal/ or /products/)
1. In public_html/, create a folder named 'portal' (or any preferred name).
2. Upload and extract all files inside public_html/portal/.
3. Visit https://yourdomain.com/portal/ to view the live site.

OPTION 3: WordPress Page Embed
1. Upload the files to public_html/portal/
2. In your WordPress dashboard, create a new Page (e.g. "Products & Solutions").
3. Add a "Custom HTML" block (or Elementor HTML block) and paste:
   <iframe src="/portal/" style="width:100%; height:100vh; border:none;" loading="lazy"></iframe>
4. Publish the page.

FILES INCLUDED IN THIS PACKAGE:

- assets/ (Bundled stylesheets & lightning-fast JavaScript)
- products/ (High-resolution industrial product photography)
- .htaccess (Apache server rewrite & caching rules)
